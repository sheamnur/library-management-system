
# Library Management System

A Library Management System built with Python, Flask, and PostgreSQL.

## Features

- Book management: add, view, search, update, and delete books
- Member management: register, view, search, update, and delete members
- Borrow and return books
- Track borrowing history
- View current and overdue borrowings
- Manage book categories

## Technologies Used

- Python
- Flask
- PostgreSQL
- Psycopg
- python-dotenv

## Setup

1. Clone this repository.
2. Install the required Python packages.
3. Create a PostgreSQL database and configure the database connection.
4. Create a `.env` file with your database password.
5. Run the Flask application.
